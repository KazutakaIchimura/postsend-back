# フロントエンドチームへ：CORS設定変更のお知らせ

## 変更内容
バックエンドAPI（spring_sendmail）のCORS設定を、これまでの「全オリジン許可」から
「許可リスト方式」に変更しました。今後は **登録されたオリジンからのリクエストのみ** が許可されます。

## お願いしたいこと
以下の情報を教えてください。バックエンド側の環境変数 `CORS_ALLOWED_ORIGINS` に登録します。

1. **本番のVercel URL**（例: `https://your-app.vercel.app` や独自ドメインなど）
2. **プレビューデプロイのURL（使う場合）**
   - VercelのPRプレビューはデプロイごとにURLが変わるため、固定できない場合は
     - 「プレビュー環境からは現状APIを叩かない」運用にする
     - もしくは特定のブランチ用に固定のプレビューURL（Vercelの「Branch Domains」機能等）を用意してそのURLを共有する
   のいずれかをご検討ください
3. **ローカル開発のURL**（参考: 現在は `http://localhost:3000`, `http://localhost:5173` をデフォルトで許可しています。Vite/CRA以外のポートを使う場合は教えてください）

## フロントエンド実装上の注意（Cookieセッション認証）
このAPIはセッションCookie（`JSESSIONID`）による認証方式です。CORS経由でCookieをやり取りするため、
フロントエンド側のHTTPクライアント設定で **資格情報を含める設定** を必ず有効にしてください。

- `fetch` の場合: `credentials: 'include'`
- `axios` の場合: `withCredentials: true`

これが設定されていないと、ログインは成功してもセッションが維持されず、以降のAPIリクエストが
認証エラー（401）になります。

## レスポンス形式の変更（sendMonth）
郵便物送付管理（`MailSend`）関連APIのレスポンスに含まれる `sendMonth` フィールドの形式に
不具合があり、修正しました（Issue #54 / PR #58）。

- 修正前: `"2026-06-01"` のような日付形式（`yyyy-MM-dd`）で返却される不具合がありました
- 修正後: `"2026-06"` のような **年月形式（`yyyy-MM`）** で返却されます（日付情報は持ちません）

`sendMonth` を日付としてパースしている場合は、年月形式の文字列として扱うように
実装をご確認ください。Swagger UI（`/swagger-ui.html`）のスキーマ定義もあわせて修正済みです。
